## 📖 عن التطبيق (Overview)

**هندلها (Handelha)** هو تطبيق إدارة مهام ومشروعات مصمم لمساعدة الأفراد والمحترفين على العمل بتركيز وهدوء، بعيدًا عن فوضى التنبيهات والإجهاد الرقمي. يجمع التطبيق بين واجهة مستخدم أنيقة وسهلة الاستخدام وأدوات ذكية لتنظيم الوقت، تحديد الأولويات، وتتبع التقدّم عبر مشاريع متعددة.

يقدّم هندلها مزيجًا من الميزات العملية: مساحات عمل منفصلة لكل مشروع لتنظيم المهام والأفكار، لوحة قيادة تبين أولويات اليوم وتقدّم العمل، جلسات تركيز مدمجة مستوحاة من تقنية بومودورو، ونظام تحليلات يوفّر رؤى عن كيفية استغلال وقتك. كما يتضمن مساعدًا ذكيًا يعتمد على تقنيات الذكاء الاصطناعي لمساعدتك في التخطيط، اقتراح مهام جديدة، وتحويل الأفكار إلى خطوات قابلة للتنفيذ.

تم تصميم هندلها أيضًا ليحافظ على راحة العين وتجربة استخدام راقية؛ ثيمات هادئة، دعم شامل للوضع الداكن، وألوان ديناميكية تتكيف مع كل مشروع، لتمنحك بيئة عمل مريحة ومحفزة على الإنتاجية المستدامة.

بإيجاز: هندلها يهدف إلى تحويل طريقة عملك اليومية إلى تجربة أكثر تركيزًا وتنظيمًا، مع أدوات ذكية وبديهية تدعم تحقيق الأهداف دون ضغط زائد.

## ✨ المميزات الرئيسية (Key Features)

* 📅 **لوحة القيادة الذكية (Smart Dashboard):** نظرة عامة على أولويات يومك، المهام العاجلة، ومستوى التقدم مع إمكانية إ[...]
* 📂 **مساحات عمل المشاريع (Project Workspaces):** إدارة متكاملة لكل مشروع على حدة مع تبويبات مخصصة لـ (المهام، الأفكار،[...]
* 📊 **التحليلات الذكية (Advanced Analytics):** رسوم بيانية توضح توزيع وقتك، أدائك، وساعات العمل المنجزة داخل كل مشروع.
* 🤖 **المساعد الشخصي (AI Assistant):** دردشة تفاعلية لمساعدتك في التخطيط، اقتراح مهام جديدة، وتحويل أفكارك الكبيرة [...]
* 🎯 **جلسات التركيز (Focus Sessions):** أداة مدمجة تشبه تقنية بومودورو (Pomodoro) لمساعدتك على الإنجاز العميق بدون تشتت.
* 🎨 **تصميم مريح وتجاوبي (Calm & Adaptive UI):** 
  * تصميم يعتمد على ألوان هادئة وطبيعية (أخضر زمردي، درجات بنفسجية، طيني).
  * دعم كامل ومثالي للوضع الليلي (Semantic Dark Mode) يحمي العين ويوفر تجربة استخدام فاخرة.
  * ألوان ديناميكية متغيرة بناءً على لون كل مشروع.

## 🛠 البنية التقنية (Tech Stack)

تم بناء التطبيق باستخدام أحدث التقنيات وأفضل الممارسات (Best Practices) في عالم تطوير تطبيقات Flutter:

* **إطار العمل:** [Flutter](https://flutter.dev) (SDK > 3.13)

## 🚀 كيفية التشغيل (Getting Started)

للبدء في تطوير أو تشغيل التطبيق على بيئتك المحلية، اتبع الخطوات التالية:

### 1. المتطلبات المسبقة (Prerequisites)
تأكد من تنصيب [Flutter SDK](https://docs.flutter.dev/get-started/install) بإصدار لا يقل عن `3.13.5`.

### 2. تثبيت الحزم (Install Dependencies)
```bash
flutter pub get
```

### 3. توليد الكود (Code Generation)
نظراً لاستخدام `Riverpod` و `Freezed`، قم بتشغيل أمر توليد الكود:
```bash
flutter pub run build_runner build --delete-conflicting-outputs
```

### 4. تشغيل التطبيق (Run the App)
```bash
flutter run
```
