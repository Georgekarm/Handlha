# هندلها — تطبيق Flutter

تطبيق عربي من اليمين إلى اليسار لتنظيم اليوم والمهام والمشاريع، مع مساعد محادثة وجلسة تركيز. أُعيد ترتيب الشاشات لتتبع الهوية المرئية الجديدة: أخضر هادئ، مساحات فاتحة، لمسات بنفسجية وطينية، وخط عربي واضح.

## تشغيل المشروع

```bash
flutter pub get
flutter run
```

لتشغيل اختبارات الواجهة:

```bash
flutter test
```

## التنقل الرئيسي

- **اليوم:** المهمة التالية، أولويات النهار، وإضافة سريعة للوارد.
- **المهام:** تبويبات اليوم والوارد والمكتملة، مع البحث والإضافة والإنجاز.
- **المشاريع:** تصفية المشاريع، إنشاء مشروع، وفتح مساحة العمل.
- **المساعد:** محادثة واقتراح مهام قابلة للتأكيد.

التنبيهات والإعدادات وجلسة التركيز ومساحة المشروع صفحات مستقلة. بيانات المهام محلية حاليًا باستخدام `SharedPreferences`.

## ملاحظة

لم يتوفر Flutter SDK داخل بيئة إعداد هذه النسخة؛ لذلك يلزم تشغيل `flutter pub get`, `flutter analyze` و`flutter test` على جهاز التطوير قبل الدمج النهائي.
