# ملخص تحسينات AI

## ما اتعدل

1. تقوية `system_prompt.dart` بتصنيف النية قبل اختيار الأداة، والتأكيد على عدم إنشاء/حذف/تعديل بيانات بسبب كلمة مفتاحية فقط.
2. إضافة أمثلة صريحة للنفي، والأسئلة، والنية المستقبلية، والجمع بين طلبات متعددة، ومنع ادعاء نجاح لم تؤكده نتيجة أداة.
3. توضيح قواعد اختيار عنوان المهمة للحفاظ على أسماء المواد والتقنيات وعدم حذف كلمات مهمة.
4. إضافة `ArabicText.normalizeForMatching` و`matchesForSearch` لتطبيع النصوص العربية للمقارنة فقط: الأرقام العربية، أشكال الألف، الألف المقصورة، التشكيل والتطويل وعلامات الترقيم. لا تستخدم النص المطبع بدل عنوان المهمة الأصلي.
5. إضافة اختبارات unit لتطبيع النصوص، وحالات تقييم حي إضافية للأسئلة والنفي واللهجة.
6. إضافة `AI_BACKEND_CONTRACT_AR.md` لتوضيح عقد الربط للـ Backend developer دون تضمين تنفيذ Backend.

## حدود النسخة

- لم يتم تدريب موديل جديد؛ التحسينات هنا على سلوك التوجيه والتعليمات والتحقق والاختبارات حول الموديل.
- جودة الإجابات النهائية تحتاج اختبارًا حيًا على الموديل الفعلي.
- لم يتم تشغيل `flutter test` أو `flutter analyze` في بيئة إعداد الملف لأن Flutter/Dart SDK غير متاحين فيها.
- لا يوجد Backend implementation في حزمة التسليم، حسب نطاق العمل المطلوب.
